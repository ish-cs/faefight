## Baked shipping container (original, CC0)

`models/container.glb` and `textures/container/` (albedo / normal / ARM atlas) are generated by
`scripts/blender/container/build_container.py` (Blender, seeded, reproducible): an original high-poly ISO 20 ft container
baked onto a low-poly model. The only third-party input is the Poly Haven **Rusty Painted Metal** scan above (CC0, Amal
Kumar), tiled into the paint mottling and rust grain; its normal map also serves as the runtime close-up detail normal.
The stencils use Blender's built-in font (Bfont/DejaVu, free licence; rendered into the texture, no font shipped) and a
fictional owner code. Released as CC0.

## Baked bunker + quay wall (original, CC0)

`models/structures.glb` and `textures/structure/` (albedo / normal / ARM atlas) are generated by
`scripts/blender/structures/build_structures.py` (Blender, seeded, reproducible): the island bunker (built from the sim's
own wall boxes) and a module of the island rim's quay wall, with baked bevels + AO and procedurally composed formwork,
damage, rebar, stains and tide zone. No third-party input in the files; at runtime the Poly Haven **Concrete Wall** scan
above adds close-up grain. Released as CC0.

Everything else (signage, palm fronds, bark, crack masks, ground markings/decals, grass blades, pebbles, gulls, boats) is
generated procedurally at runtime in `src/client/world/`.

## Audio

There are no audio files. Every sound effect, ambience loop and the music is synthesized at runtime with the
Web Audio API (oscillators, filtered noise, envelopes) by original code in this repo, so nothing is downloaded or
decoded and there is no third-party audio licence to track. The synthesized audio is dedicated to the public
domain (CC0 1.0, https://creativecommons.org/publicdomain/zero/1.0/).

| What | Source | Licence |
|---|---|---|

| Adaptive music (calm / tense / intense) | `src/client/audio/music.ts` (procedural, live-sequenced) | CC0, original |
